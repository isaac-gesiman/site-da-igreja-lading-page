# Site da Igreja Batista Getsêmani - Mossoró

Este é o site oficial (landing page) da **Igreja Batista Getsêmani**, localizada em Mossoró, Rio Grande do Norte. O site tem como objetivo principal servir como um ponto de encontro digital para membros e visitantes, facilitando o acesso às informações sobre a igreja, sua história, atividades e formas de contato.

## Sobre o Site

O site oferece uma visão geral das atividades da igreja, permitindo que a comunidade e novos visitantes conheçam:

- **Quem Somos:** A história da implantação da igreja, desde a sua fundação em 2012, sua visão e missão.
- **Ministérios:** Uma descrição dos diversos departamentos e ministérios que compõem a igreja, como os voltados para crianças, jovens, mulheres, homens, casais, louvor, mídia, dança e teatro.
- **Pedidos de Oração:** Uma página dedicada onde visitantes e membros podem enviar seus pedidos de oração através de um formulário integrado.
- **Informações de Contato:** Endereço da igreja em Mossoró (Planalto Treze de Maio) e canal de comunicação via e-mail.
- **Redes Sociais:** Links diretos para os perfis da igreja no Instagram, Facebook, YouTube e playlists no Spotify.
- **Programação:** Exibição dos horários dos cultos.

## Como o Site Funciona

O projeto é estruturado como uma **landing page estática**, composta por arquivos HTML, CSS e ativos de imagem/vídeo. A estrutura básica inclui:

1. **Navegação:** Um menu simples que permite transitar entre Home, História, Ministérios e Pedidos de Oração.
2. **Conteúdo:** Páginas específicas para cada seção do site, utilizando estilos definidos centralmente para garantir consistência visual.
3. **Integração Externa:** O site utiliza serviços externos para funcionalidades específicas, como formulários para pedidos de oração (Google Forms) e redes sociais para conectar a comunidade digitalmente.
4. **Infraestrutura:** O projeto é configurado para ser hospedado via Firebase Hosting, garantindo rapidez e disponibilidade no acesso.

O design do site é focado em simplicidade e clareza, buscando acolher quem chega pela primeira vez e instruir os membros sobre as atividades atuais da igreja.
